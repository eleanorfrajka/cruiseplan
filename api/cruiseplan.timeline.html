Timeline & Scheduling

Scheduling algorithms and timeline generation for cruise planning.

cruiseplan.timeline package.

This package contains scheduling and timeline generation modules for cruise planning:

  • record: the timeline record (ActivityRecord) and Timeline

  • distance: Geographic distance calculations using Haversine formula

  • duration: Time duration calculations for cruise operations and activities

  • scheduler: Core scheduling logic for generating cruise timelines

These modules provide the mathematical and algorithmic foundation for determining distances, durations and scheduling sequences in oceanographic cruises.

cruiseplan.timeline.distance module

Geographic distance calculations for cruise planning.

This module provides functions for calculating distances between geographic points using the Haversine formula, which gives Great Circle distances on a spherical Earth. Includes utilities for route distance calculation and unit conversions between kilometers and nautical miles.

cruiseplan.timeline.scheduler module

Clean scheduler implementation with unified operations model.

The scheduler treats every activity as an operation with entry and exit coordinates: - Operations (science) are kept separate from navigational transits (connections) - All distances are computed in one coordinate system

cruiseplan.timeline.scheduler.trim_overlaps(timeline: list[ActivityRecord]) → list[ActivityRecord][source]

Shorten each record that runs past the start of the next one.

A negative delay_start_minutes means the previous activity ended early: the next record starts before the previous one ends. The previous record is ended where the next one starts (its duration is never below zero); planned_duration_minutes keeps the planned value. The sum of the durations then equals the elapsed time, and the schedule matches what the forecast shows.

Parameters:

timeline (Timeline) – Records in schedule order.

Returns:

A new list; trimmed records are replaced by copies.

Return type:

Timeline
